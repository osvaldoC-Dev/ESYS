Egress Events

Monitor outbound activity, review suspicious events, and track system decisions.

Connection required

Connect your event store to start receiving and reviewing egress events. Credentials are injected at build time from Vercel — nothing is stored in this codebase.

Environment variables → Deploy → Events
Configure Supabase
  1. In Vercel: Project Settings → Environment Variables. Add SUPABASE_URL and SUPABASE_ANON_KEY (the anon key only).
  2. Confirm the table has a read-only policy for anon: 
    select policyname, roles, cmd
from pg_policies
where tablename = 'esys_events';
  3. Redeploy — the build step injects the variables into this page automatically.
